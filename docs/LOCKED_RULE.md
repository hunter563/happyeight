# 当前唯一预测规则

用户选定《快乐8_杀号优化_100期复核.xlsx》的评分模型主方案。后台与网页统一为 `shift20-rf-1.0.0`，策略键 `locked_rf`。

## 固定执行流程

1. 目标为 N 期，只读 N 之前连续12期；原始号码来自 N−2 期。
2. 将 N−2 的20个开奖号码分别 −1、+1，剔除0/81，合并重复。先按支持次数降序，再以 N−2 期号为固定随机种子打破同分，取20个候选。
3. 用近期频率、遗漏、邻号、五类图形及历史12条规则投票等35项特征评分。图形和规则投票是同一个冻结模型的内部特征，不是额外可切换的预测器。
4. 使用冻结随机森林 `RF_5_80`：160棵树、最大深度5、最小叶样本80，训练截止2026178。不在线拟合，不按新开奖结果换参数。
5. 按分数降序，取累计分数达到4所需的最少数量，限制为10–14个；并列时保留候选生成顺序。该累计分数不是命中保证。
6. 保存所有20个候选、评分、保留和删除号码、历史截止期、来源期号、输入和模型的 SHA256。数据导入后按保存号码核对，历史记录不重算。

最终选号未额外强制奇偶或十号区间配额；旧配额逻辑仅作为历史规则投票特征的一部分，保证与用户选定表格完全一致。

## 模型文件与可复核性

模型文件：`fusion/models/shift20_rf_v1.json`，SHA256：

```text
1f1abe90572392979abfd69d3c710cced3692b0902dbe6c9bdfbcfa499fe423d
```

模型由既有优化研究的 `optimized-kill-frozen.joblib` 中 `RF_5_80` 精确导出，保留所有树节点与叶概率。推理输入先转 float32，与原 sklearn 森林保持一致；运行时使用 JSON 和 NumPy，不加载 pickle，不依赖 sklearn。

`tests/fixtures/locked_rf_reference.json` 保存100期逐期参考与必要112期历史。测试核对每期选号、命中、误删号码，并核对首末期全部20个评分，另测目标结果隔离、缺期、训练截止和接口禁用。

## 后台边界

- `/api/predict`、`/api/experiments` 创建记录，以及 `/api/analysis`、`/api/backtest`，只调用该模型。
- 不允许通过 `k`、`window`、`model` 或 `strategy` 修改预测配置。
- `/api/geometry`、`/api/geometry/predict`、`/api/geometry/backtest` 返回410；`/geometry.js` 不再提供。
- `/api/status` 的 `engines` 仅有 `locked_rf`；健康检查返回 `activeRule` 版本。
- 旧版本记录默认从当前预测列表隐藏，通过 `includeArchived=1` 读取；SQLite 原记录、号码、日期和指纹保持原样。
- 仅部署应用代码与模型，不迁移或清空 `/data/fusion.sqlite`，不改访问认证。
