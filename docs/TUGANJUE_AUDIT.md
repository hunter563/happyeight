# 图感觉快乐8公开规则独立重建（阶段一）

来源： https://tb.tuganjue.com/i-l-kl8.html （公开说明页，2026-10-21检查）

## 已完成
新增 `fusion/chart_indicators.py`，基于数学定义独立实现开奖和值、跨度、奇偶、大小、尾数、各模余数分布（3–14）、区间分组、数字包含分布、五行及波色公开映射、对望码、连号、相邻两期重号与逐位升平降/振幅，及近N期频率、遗漏排序。概率基准为精确超几何分布。未调用对方接口，也没有复制对方源码。

## 与目标网站的差距
目标展示104种统计走势图，但首页文字介绍不等于完整实现规范。部分图使用非均等分区、特殊网格排列、站方自定义质合定义；本站另有相应图表渲染、可视化配置、历史数据服务。**尚未验证细节的图绝不能称1:1还原**。公开目录中的“选号逻辑”多为事后描述性统计，不代表含隐藏有效预测算法。

## 最重要的架构边界
现有快乐8项目的 `shift20-rf-1.0.0` 为锁定的唯一选号服务。此新文件只是**独立的统计研究模块**，未接入 `/api/predict`、`/api/backtest` 或覆盖既有模型，未改写历史数据和界面，也不改变上线部署。后续先加入只读统计API和独立分析页，人工核验图表对齐后再接入；不得使用开奖号码泄露目标期。

## 尚需继续逐项核验
1. 点击104个子页面，记录图表选项、默认期数、排列、筛选和行列结构。
2. 核对可公开访问的接口和网络数据格式；不绕过登录/访问控制。
3. 从站内选3-5个期号验证每个已实现指标；若站方非标准分区规则，以站方明示列表为准，不默默推定。
4. 追加只读统计接口、图表前端、单元测试；保持原预测模块独立。
5. 历史回测遵守目标期结果隔离，和固定随机基准比较，不能将走势指标宣传为提高中奖率的证明。


## 2026-10-21 追加：重复、邻号与连出指标（第五阶段）
- `fusion/chart_trends.py` 增加上期重号、上期±1邻号、新邻号、十号区间及尾数分布、连续出现次数统计。
- `fusion/chart_series.py` 在历史走势图只读接口加入 `rows[].trend` 和 `streakSummary`；前端已增加对应列。未修改已有固定预测模型。
- 规则说明：当期号码若与上一期某号码相同是“重号”；若相差1则是“邻号”（同一个号码可能同时符合邻号与重号的统计体系，统计项目不互斥）。“新邻号”指是邻号但不属于上期重号。前一期开奖结果未知时，不计算重号/邻号。
- 观察窗口的首期没有更早一期上下文，因此该首期重号/邻号显示为无数据。完整历史遗漏另按观察窗口处理。
- 这组统计是**公开名称下的独立规则实现**，尚不能断言与对方所有图表的计算口径完全一致。
- 新增 `tests/test_chart_trends.py`，提交成功但未通过本地/CI执行验收；禁止用代码提交代替已测试/已部署结论。
