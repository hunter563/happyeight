## 验收标准
1. 核查原页面的公开图表交互、统计口径、期号和数据，并保存可复核证据。
2. 我们独立实现对应的数据、ECharts可视化和切换；固定预测器永不自动改变。
3. 使用相同期号逐值比对，修复差异，执行单元测试和实际浏览器测试。
4. 未经核验不可宣称104/106图已1:1复刻，也不可宣称走势可以预测随机开奖。
5. 原站介绍个别地方与列举号码存在笔误（例如和81表中“1,50”），不能直接信任，需要用可证伪的数学规则验证。
